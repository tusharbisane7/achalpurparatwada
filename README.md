# Achalpur Paratwada – Digital Regional Portal

React + Vite frontend for the Achalpur–Paratwada regional information portal.

## Requirements
- Node.js 18.18+ (Node.js 20 LTS recommended)
- npm 9+

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Stack
- React 18
- Vite 6
- React Router 6
- Sass / SCSS
- Lucide React icons

## Notes
- JSX files explicitly import React for compatibility with classic JSX transforms.
- `vite.config.js` also enables the automatic JSX runtime.
- The current project is a frontend prototype. Authentication, listing submissions, complaint tracking, moderation, and live directory data require a backend/API before production use.
- Verify all local listings, phone numbers, official links, schedules, and emergency information before publishing.
